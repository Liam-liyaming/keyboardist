# 调研：打字光效与生成音乐质量

> 目标：让「键盘手」的两条命门——**即时光效**与**每日之歌**——从"能跑"走到"好用、好听"。
> 本文汇总三路并行调研 + 我们自己代码的实测体检，所有结论标注【共识】或【经验】。

---

## 执行摘要

三条最影响决策的结论：

1. **光效的硬约束是延迟，不是亮度。** 击键到视觉的起手必须 ≤1 帧（≈16ms），工程预算 30–55ms；想增强存在感要加**衰减尾部**（200–400ms），而不是加亮度或加粒子——后者会把外围反馈变成一次"通知"，而打断的恢复成本是分钟级【共识】。
2. **"廉价感"不是音色问题，是结构问题。** 可预测 + 密度均匀 + 没有呼吸 = 练习曲。人性化要**长程相关**的时序偏差，白噪声抖动无效【共识，Hennig 2011】。
3. **我们手上最稀缺的资产，恰恰是打字本身的击键间隔。** 它是天然的长程相关人类时序数据——应该用它驱动节奏与力度，而不是把键位映射成音高。这是零成本拿到"人味"的路。

## 一、打字光效

### 1.1 延迟预算（最硬的约束）

| 环节 | 参考值 | 来源 |
|---|---|---|
| 击键→字符可察觉阈值 | 单键 165ms、连续输入 100ms | Boyle & Lanzetta, 1984 |
| 通用"即时感" | 0.1s | Nielsen |
| AV 同步可察觉 | +45ms / −125ms（声先/声后） | ITU-R BT.1359-1 |

推算：事件扫描 1–8ms + 传递 1–8ms + 一帧 16.7ms + 显示 10–20ms ≈ **30–55ms**。

**结论**：起手必须当帧，衰减可以慢慢来；"预备动作"要做成 keydown 当帧的微缩放，而不是延迟播放。

### 1.2 外围通道：能感知，但不抢注意力

- Calm technology（Weiser & Brown, 1996）：技术应在"中心—外围"之间平滑移动，不索取注意。
- Tangible Bits（Ishii & Ullmer, 1997）：光、声、气流承载"背景比特"。
- 中断代价（Iqbal & Horvitz, CHI 2007）：被打断后约 10 分钟切换 + 10–15 分钟回到原任务。

**设计启示**【经验】：外围视觉分辨率低、时间分辨率高——用**大面积低频光晕**，不用锐利小图形；靠"变化"被感知，而非绝对亮度。

### 1.3 技术取舍

| 技术 | 判断 |
|---|---|
| Bloom | 唯一值得的"贵"效果；1/2、1/4 金字塔降采样，阈值 ~0.9（gamma 空间） |
| 粒子 vs 弹簧 | **临界阻尼弹簧**（response 0.3–0.4s）便宜一个量级且物理正确；粒子只做 <300ms 一次性爆发 |
| 噪声流场 | curl noise 无散度，看起来是"流"而非"抖" |
| 能量扩散 | 热传导 = 几次小核模糊；反应扩散只在屏保场景值得 |
| 色彩 | sRGB 混合；OKLCH 只用于取色与色阶（等感知亮度） |
| 色调映射 | ACES 拟合做高光滚降，防 bloom 糊成白块 |
| 省电 | 静止降帧；支持 prefers-reduced-motion（WCAG 2.3.3） |

### 1.4 五个改进点（性价比序）

1. **keydown 当帧起手 + 临界阻尼弹簧衰减** —— 零成本，解决"死手感"
2. **单光斑 + 1/4 分辨率 bloom** —— "贵感"的主要来源
3. **分层衰减**：亮度 80ms、尺寸 300ms、色相不动 —— 造余韵，不造事件
4. **OKLCH 生成 2–3 档等亮度色阶** —— 替代随机换色
5. **空闲 2s 降级到 30fps** —— 输入即恢复

### 1.5 参考

Razer Chroma REACTIVE（逐键触发+衰减，行业基线）、[Keyviz](https://github.com/mulaRahul/keyviz)（开源击键可视化）、Epistory（打字驱动世界）、MilkDrop/projectM（参数化低频驱动）、teamLab（触摸→光扩散）。

## 二、生成音乐质量

### 2.1 廉价感的根因

| 层面 | 症状 | 根因 |
|---|---|---|
| 和声 | 和弦都对但不对味 | 只保邻接合法，不建模张力累积与延迟解决 |
| 声部进行 | 平行五八度、导音不解决 | 各声部独立采样，禁则在语料中罕见 |
| 旋律 | 音域窄、方向随机、无高潮 | 随机游走，无拱形轮廓、无动机记忆 |
| 律动 | 机械、同质 | 全量化到网格，力度平坦 |
| 配器 | 音色全在场、糊 | 无频段分工、无前后景 |
| 混音 | 响而薄 | 靠限幅器硬推，无总线/侧链 |

### 2.2 专业做法

- **动机发展**：模进、倒影、扩缩、移位、碎片化。铁律：精确重复 ≤2 次，第 3 次必变形，但保留轮廓或节奏型之一。
- **动态弧线**：用"能量"（密度 × 音区 × 高频占比 × 侧链深度），不是音量。build 靠叠层与滤波打开；drop 前留 1–2 拍空白（最便宜的 hook）。
- **人性化**【共识】：听众偏好**长程相关**的微时序偏差，而非白噪声抖动（Hennig et al., PLoS ONE 2011，39 人听测）。做法：hi-hat 提前 5–15ms、snare 落后、bass 锁 kick；力度按重音型浮动；每声部**固定**失谐 ±3–7 cents。
- **分层配器**：20–60 / 60–250 / 250–2k / 2–6k / 6–16k 五段分工；同八度活跃声部 ≤3。
- **总线**：非低频全高通；2–4k 给 lead 让路；2:1 慢起音胶水压缩；混响只送中后景。目标 **−14 LUFS-I**、真峰 ≤ −1 dBTP、LRA 6–10 LU。

### 2.3 评测的真相

| 指标 | 测什么 | 局限 |
|---|---|---|
| FAD | 嵌入分布距离 | 样本量偏差、参考集偏置；对和声与结构不敏感 |
| CLAP | 文本-音频对齐 | 只测"像不像 prompt"，与好听几乎无关 |
| MOS | 主观偏好 | 昂贵不可复现，需 ≥15–20 人 |

**建议分层**：信号层（LUFS/真峰/频谱斜率）→ 符号层（和声合法性、动机重复率）→ 感知层（MUSHRA/ABX）→ 任务层。只报 FAD 等于没测。

### 2.4 五个改进点（性价比序）

| # | 改进 | 量化目标 |
|---|---|---|
| 1 | 结构模板 + 能量弧（A-A'-B-A''，32 小节） | 4 段；段间密度差 ≥2×；能量峰在 60–80% |
| 2 | 总线链与响度交付 | −14 LUFS-I，真峰 ≤ −1 dBTP，LRA 6–10 LU |
| 3 | 频段分工 + 侧链 | 60–250 占 30–40%、250–2k 35–45%、2–6k 8–15% |
| 4 | 人性化（长程相关时序） | σ 3–8ms；力度动态 ≥18dB；±4–7 cents |
| 5 | 动机变异引擎 | 动机家族 ≤4、每族变体 ≥6、精确重复 ≤2、密度 4–8 note/s |

## 三、竞品与差异化

现有产品各缺一环：统计工具（WhatPulse/WakaTime）不产出审美产物；RGB 灯效（Chroma/iCUE）不形成记忆；生成音乐（Endel/Bloom）不含"你的"数据。

**空位是"日终仪式"**：不做常驻，而是每晚一次"把你的今天听完"。

**最可能的失败原因**：
1. 新鲜感衰减——映射是任意的，两周后沦为壁纸；
2. 隐私反噬——被质疑是键盘记录器；
3. 音乐难听——不如静音；
4. 没有分享闭环——不美、不像"我"就不会被发出去。

前两条我们在架构上已处理（只存整数、本地、安全输入自动停）；后两条是接下来的主战场。

## 四、我们的实测体检（v0.3 → 本轮改动后）

| 指标 | 当前 | 研究目标 | 差距 |
|---|---|---|---|
| 响度 | −18.0 dBFS RMS（≈ −15 LUFS） | −14 LUFS | 略轻 |
| 60–250Hz | 0.647 | 0.30–0.40 | **偏重** |
| 250–2k | 0.341 | 0.35–0.45 | 接近 |
| 2–6k | 0.010 | 0.08–0.15 | **严重不足** |
| 真峰 | −3.7 dBFS | ≤ −1 dBTP | 有余量 |
| 人性化 | 起点 ±6ms、力度 ±10% | σ 3–8ms、动态 ≥18dB | 达标 |
| 动态弧线 | 0.74 → 1.0 → 0.68 | 能量峰在 60–80% | 达标 |
| 会话上限 | 8 段抽样 | 避免流水账 | 达标 |

**注意**：FFT 频段能量比不完全等于感知响度，低频正弦天然占能量大头。上面的"偏重"需要在真机上用耳朵复核，不能只看数字。

本轮已落地：人性化抖动、动态弧线、响度标准化到 −18 dBFS RMS、会话抽样上限、高频闪光层、2.5kHz 高架提亮。

## 五、路线图

**P0（已完成）**
- 会话抽样（≤8 段）、动态弧线、人性化抖动、响度标准化、高频补光

**P1（下一步，性价比最高）**
- 动机家族 + 变形引擎（精确重复 ≤2、每族 ≥6 变体）
- 频段分工：bass 独占 60–250、pad 250–2k、melody 2–6k 补足
- 真峰限幅器 + LUFS 测量（把"响度"从经验变成可验收指标）
- 光效：弹簧物理 + 分层衰减

**P2**
- 用**真实击键间隔**驱动节奏（需在采集层存 interval 直方图，仍是整数，不涉内容）
- 风格引擎（pop / rap 进 App）
- bloom 后处理（Metal）
