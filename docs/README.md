## 被验证过的工程细节

- **CGEventTap 是唯一可靠的击键通道**，`NSEvent` 全局监听在 macOS 26 上基本不触发
- **Electron / Chromium 默认不建可访问性树**，需要显式设 `AXManualAccessibility` / `AXEnhancedUserInterface`
- **ad-hoc 签名每次编译都会丢 TCC 权限**，必须用稳定证书（见 `scripts/create-signing-cert.sh`）
- **中文 IME 组合态**会让 AX 长度增量剧烈抖动，净增量仍然正确
- **headless Chrome 抓不到 canvas**，验证可视化要把 `toDataURL()` 写进 DOM 再取回
